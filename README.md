# しずかにしりとり

1台のスマホを順番に回して、声を出さずに遊べるしりとりアプリです。
図書館や電車の中など、話せない場所で遊ぶことを想定しています。

## 遊び方

1. プレイヤーの名前を登録し、ルールを選んで「はじめる」
2. 「次は ○○ さん」と表示されたらスマホを渡す
3. 受け取った人が「受け取った！」をタップして、アプリ内のフリックキーボードで答えを入力
   (予測変換がヒントにならないよう、スマホのキーボードは使いません。iPhone のかなキーボードと同じ配置で、フリックと連続タップの両方で入力できます。濁点・小さい文字は「゛゜小」キーで切り替え)
4. お題なしで「みんなで判定」がオンなら、ほかの人が ⭕ / ❌ で判定(反対が過半数で脱落)
5. 「ん」で終わる・時間切れ・こうさん・判定で却下されると脱落。最後の1人が勝ち

## 1人用モード

設定画面の上で「1人で」を選ぶと遊べます。お題は「国名」で、答えはアプリが自動で判定します。

| モード | 内容 |
|---|---|
| CPUと対戦 | CPU と交互に国名をつなぐ。強さは よわい(ときどきこうさん・「ん」で終わる国も出す) / ふつう(「ん」で終わる国は避ける) / つよい(あなたが続けにくい文字で終わる国を選ぶ。作戦ルールなら行き止まりを狙う) |
| タイムアタック | 60秒で何か国つなげられるか。「ん」で終わる国は使えない。自己ベストを端末に保存 |

1人用の「行き止まり」ルールは、みんなで遊ぶときの設定とは別に保存します(初期値は のんびり)。作戦ルールは上級者向けで、CPU はつながった数が10未満の序盤は詰みを狙わず、中盤以降も「つよい」がときどき狙うだけです。

## ルール設定

| 設定 | 内容 |
|---|---|
| お題 | なし(自由) / 国名。国名は197か国(国連加盟国+バチカン・コソボ・クック諸島・ニウエ)の一覧で自動判定します。「アメリカ」「べいこく」などよく使う呼び方もOK。続く国が残っていない文字の扱いは「行き止まり」で選べます |
| 行き止まり(お題ありのとき) | のんびり: 濁点を外して続け(ご→こ)、それでもなければランダムに引き直す / 作戦: 行き止まりの答え(国名なら「トーゴ」など)を出されたら次の人が脱落 |
| 制限時間 | なし / 15秒 / 30秒 / 60秒。残り時間は色とバイブで知らせます(音は出ません) |
| 最初の言葉 | 「しりとり」から / ランダムな文字から |
| 「ー」で終わる言葉 | コーヒー → 「ひ」 / コーヒー → 「い」(母音) |
| 濁点・半濁点 | 区別する / 区別しない(か＝が＝ぱ) |
| みんなで判定 | 答えが実在する言葉かを ⭕❌ の多数決で決める |

作戦ルールで詰まされたときは、脱落画面で理由(もともとその文字で始まる答えがないのか、出し尽くしたのか)を説明し、結果画面に「詰みの国」(トーゴ・スリナムなど)の一覧を表示します。

お題ありで、時間切れ・こうさん・「ん」で終わる答えで脱落した人には、結果画面に「まだこんな答えがあったよ」として、その文字で始まる答えを最大3件(+残りの数)表示します。次の人へのヒントにならないよう、脱落したその場では出しません。

小さい文字は大きい文字として扱います(きしゃ → や)。「を」は「お」として扱います。

## 開発

ビルド不要の静的サイトです。`public/` がそのまま公開されます。

```sh
npm test      # 文字判定ロジックのテスト
npm start     # http://localhost:3000 で確認
```

## 公開(GitHub Pages)

`main` に push すると GitHub Actions がテストを実行し、`public/` を GitHub Pages に公開します。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開URL: `https://<ユーザー名>.github.io/shiritori/`
